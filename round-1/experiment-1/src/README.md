# Measuring Zipfian Curvature in Narrative Windows

This experiment investigates the relationship between Zipf-Mandelbrot curvature drift and semantic drift in narrative text, using Jane Austen's *Pride and Prejudice* as a case study.

## Overview

The hypothesis is that changes in the curvature parameter (b) of the Zipf-Mandelbrot distribution across narrative windows correlate with semantic drift (measured as centroid drift in embedding space). The experiment compares:

1. **Primary method**: Zipf-Mandelbrot MLE fitting with semantic centroid drift
2. **Baseline method**: Standard Zipf power-law (linear regression on log-log) with same semantic drift
3. **Control**: Shuffled-text baseline (10 permutations) to establish significance

## Methodology

1. **Text Processing**: Load *Pride and Prejudice* from Project Gutenberg Australia, tokenize (lowercase, remove punctuation, filter short tokens)
2. **Windowing**: Rolling windows of 500 tokens with 100-token stride (925 windows total)
3. **Frequency Analysis**: Compute word frequency distribution per window
4. **Zipf Fitting**: 
   - Primary: MLE for Zipf-Mandelbrot (parameters s, b)
   - Baseline: Linear regression on log(rank) vs log(frequency) for standard Zipf
5. **Semantic Drift**: Deterministic hash-based word embeddings (300-dim), cosine distance between consecutive window centroids
6. **Curvature Drift**: First difference of parameter b across windows
7. **Correlation**: Pearson and Spearman correlation between curvature drift and semantic drift
8. **Significance Testing**: Compare observed correlation against 10 shuffled-text baselines

## Results Summary

| Method | Pearson r | p-value | Spearman r | p-value | Z-score | Significance p |
|--------|-----------|---------|------------|---------|---------|----------------|
| Zipf-Mandelbrot MLE | -0.0300 | 0.3621 | -0.0081 | 0.8061 | -2.18 | 0.0293 |
| Zipf Power Law | NaN | NaN | NaN | NaN | NaN | NaN |

**Key findings:**
- The observed correlation (r = -0.0300) is not statistically significant (p = 0.36)
- However, it differs significantly from the shuffled baseline (z = -2.18, p = 0.029)
- The power-law baseline fails because parameter b is fixed at 0 (no curvature), making curvature drift always 0
- The Zipf-Mandelbrot model provides meaningful curvature variation (b ranges from ~0 to ~6.4)

## Running the Experiment

```bash
python method.py
```

The script will:
1. Load and tokenize the text
2. Create 925 windows of 500 tokens each
3. Fit Zipf-Mandelbrot MLE to each window
4. Compute semantic drift using deterministic embeddings
5. Calculate curvature drift (Δb)
6. Run 10 shuffled baselines
7. Save results to `results/exp_gen_sol_out.json`
8. Log summary statistics

## Notes on Interpretation

- The weak correlation (r ≈ -0.03) suggests no strong linear relationship between Zipfian curvature drift and semantic drift at this window size
- The significant z-score against shuffled baseline indicates the observed pattern is not purely random noise
- The power-law baseline is degenerate for this analysis (b=0 always), confirming the need for the 2-parameter Zipf-Mandelbrot model
- Future work could explore: different window sizes, alternative semantic representations (e.g., BERT embeddings), non-linear relationships, or different texts
