## Full Summary

This artifact produces a dataset of rolling windows from Pride and Prejudice (Project Gutenberg eBook #42671) for Zipf-Mandelbrot frequency distribution analysis of narrative temporal dynamics. The novel (~123K tokens) is partitioned into 2,453 overlapping windows of 750 tokens each with a 50-token step size. Each window includes the raw text segment, character and token indices, and linguistic metadata: total tokens (750), unique token count, function word count (using NLTK English stopwords), content word count, function word ratio, and type-token ratio. The dataset follows the exp_sel_data_out schema with input/output JSON strings and flat metadata fields. Outputs include full (13 MB), mini (3 examples), and preview (truncated) variants, validated against the schema. A reproducible data.py script and pinned pyproject.toml are provided.
